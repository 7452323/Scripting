# 每日图文

随机背景图片 + 一句话（一言）桌面小组件，支持小号 / 中号 / 大号三种尺寸。

## 使用说明

- **添加小组件**：在 Scripting 中添加「每日图文」小组件到桌面即可；打开 App 可查看/预览当前图文。
- **🖼 刷新图片 / 💬 刷新一言**：立即换一张背景图或换一句话，操作后桌面组件同步更新。
- **📌 固定图文**：把当前图片和一言固定到小组件（不再自动更换）；「取消固定」恢复自动刷新。
- **数据源**：随机图片 `https://imgapi.cn/cos.php`；一言 `https://v1.hitokoto.cn`。
- **刷新策略**：小组件每 4 小时自动刷新一次；在 App 内任何内容变更后立即同步。
- **缓存**：当日图文缓存于 App 共享目录（`daily_quote_bg_<日期>.jpg` + `daily_quote_meta_<日期>.json`），小组件缓存优先、断网也能显示。
- **透明/毛玻璃背景模式**：仅展示文字内容（背景由系统绘制）。
