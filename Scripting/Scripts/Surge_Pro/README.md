# Surge_Pro

## 用途
Surge HTTP API 监控面板，读取流量、出站、最近请求、DNS、规则和策略组数据，显示网络状态与历史趋势，并支持 Widget。

## 首次使用
1. 确认设备已安装并运行 Surge。
2. 在脚本设置中填写 Surge HTTP API 地址和访问凭据。
3. 测试连接成功后查看指标、请求和策略组。
4. 按需预览并添加 Widget。

## 注意事项
API 地址和 Token 只保存在本机，不要提交到仓库。关闭 Surge API 或修改端口后需要同步更新脚本设置。
