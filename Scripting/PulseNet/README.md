# PulseNet

## 用途
网络与设备监控工具，测试下载、上传、延迟和抖动，查询公网 IP 与归属地，展示设备状态和图表，并提供抢票毫秒计时悬浮窗与 Live Activity。

## 首次使用
1. 导入并运行脚本。
2. 按页面选择测速、IP 查询或设备状态功能。
3. 需要抢票计时时，先设置目标时间再启动悬浮窗或 Live Activity。
4. 首次使用扩展入口时，按系统提示完成相关权限设置。

## 注意事项
测速会消耗流量；测速结果受网络环境和服务器负载影响。计时功能只用于显示时间，不保证第三方平台抢票结果。
