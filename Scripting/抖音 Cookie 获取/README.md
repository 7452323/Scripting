# 抖音 Cookie 获取

## 用途
在 WebView 中登录抖音，读取 `douyin.com` 和 `iesdouyin.com` Cookie，调用接口验证有效性，保存最多十条记录并自动复制 Cookie。

## 首次使用
1. 导入并运行脚本。
2. 在内置 WebView 中完成抖音登录。
3. 点击获取并验证 Cookie，确认有效后保存或复制。
4. 之后可以从历史记录选择已保存的 Cookie。

## 注意事项
Cookie 等同于登录凭据，不要分享、截图或提交到仓库。账号登录和 Cookie 获取请遵守抖音服务条款。
