# ONE 每日一言

显示 ONE 每日一言内容和配图的主屏幕小组件，支持小、中、大尺寸。

## 首次使用

1. 在 Scripting App 运行“One 每日一言（新）”，确认可加载当天内容。
2. 在主屏幕添加该脚本的小组件，并选择所需尺寸。
3. 在小组件配置中可选择普通、透明或模糊背景模式。

## 数据与刷新

- 小组件每天请求一次新内容，请求时间安排在服务器发布当天内容之后（本地时间 00:05 之后）；具体时刻由 iOS 决定，日期只是“最早可以请求”的时间。
- 打开脚本会立刻刷新内容并让小组件同步重画；点击桌面小组件会打开脚本，同样会刷新。
- 拉取失败时保留上一次的内容，并在 20 分钟后重试，不会整天停在“加载失败”。
- 小组件底部“更新 MM-DD HH:mm”是最近一次成功拉取的时间，可据此判断内容是否过期。
- 运行日志写在 App Group 的 `one_log.txt`（App / 小组件每次运行的来源与结果），排查刷新问题时可以查看。

## 注意事项

- 透明、模糊和模拟透明背景模式由系统绘制背景，小组件不会覆盖壁纸。
- 普通模式显示当次获取的每日配图，并根据图像明暗调整文字颜色。
- 小组件后台刷新由 iOS 统一调度、按刷新预算分配，脚本无法强制；如果希望更稳，可打开一次脚本或点一下小组件。
- 缓存只保留当前一份（`one_data.json` + `one_bg.jpg`），旧版按天存放的缓存文件会在打开脚本时自动清理。

## 更新日志

### 1.2.0 - 2026-09-26

- 小组件改为每天刷新一次，请求时间紧跟服务器发布当天内容（本地 00:05 之后），不再每 4 小时空跑，避免被 iOS 削减后台刷新预算。
- 打开脚本会立刻刷新内容，并让桌面小组件同步重画；点击小组件也能打开脚本刷新。
- 拉取失败时保留上一次的内容并在 20 分钟后重试，不再整天停在“加载失败”。
- 缓存改为单一文件槽，不再把 base64 图片写进 JSON，并自动清理旧版遗留的多日缓存。
- 小组件底部“更新”标签补上日期，方便一眼看出内容是否过期。

### 1.1.0 - 2026-08-29

- 新增透明、模糊和模拟透明背景模式适配。
- 修复当天缓存永久命中导致 4 小时刷新后内容不重新请求的问题。
- 为缓存增加 4 小时时效和网络失败回退。
- 显示最近一次成功拉取时间，便于核对刷新状态。
