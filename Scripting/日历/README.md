# 日历

一个用 Scripting 的 TypeScript/TSX 写的日历应用：月历、日程、待办、日子四个标签页，全屏呈现。

## 功能

### 月历

- 六周月历网格，星期日开头，可左右切换月份
- 每格显示公历、农历、节气与节日
- 圆点标记当天有日程、方点标记当天有日子
- 点选日期后，下方列出当天的日程与待办
- 顶部显示下一个节气倒数

### 日程

- 读取系统日历，按日期分组展示
- 点击查看详情，可跳转到系统日历编辑或删除
- 支持全天事件与跨天事件

### 待办

- 读取系统提醒事项
- 点击划线标记完成，完成状态本地持久化
- 左滑删除

### 日子

- 记录生日、纪念日这类重要日子
- 支持公历与农历、一次性与每年重复
- 显示距今倒计时与周岁
- 点击进入编辑，左滑删除

### 其他

- 桌面小组件（小 / 中 / 大三种尺寸），不写死背景色（`widgetBackground={undefined}`），透明 / 模糊组件直接透出壁纸
- 本地通知提醒
- 六套主题色
- 外观跟随系统

## 更新日志

### 3.9.0

**桌面小组件不再写死背景色**

- 背景改为**不设自定义底色**（`widgetBackground={undefined}`），写法参照「一言小组件」：没开颜色背景时就是 undefined
- 不铺底就交给 Scripting / 系统：普通组件用系统默认材质，透明 / 模糊 / 图片模拟透明组件直接透出壁纸
- 之前写死的浅白 / 深黑会把这层底衬盖住 —— 「透明背景没了」的来因
- 补上文档要求的 `Script.exit()`

### 3.8.3

- 设置页去掉「更新日志」行
- 新增「关于」卡片，用一句话说明应用是做什么的

### 3.8.2

**修复作者头像显示不完整**

- 头像是 460×460 的原图直接塞进 40pt 的框里，缩放没生效时就会被裁成左上角一小块
- 改为预先缩成 120×120 的本地文件，并显式开启 `resizable`

### 3.8.1

- 界面名称改为「日历」
- 设置页底部增加作者信息，点击跳转 GitHub
- 清理开发期遗留的内部命名

### 3.8.0

**全局配色调整为暖白**

- 页面底色 `#FBF4E9` → `#F7F4F0`：原来的偏黄奶油色大面积铺开会显「脏」，换成保留一点暖意但干净得多的暖白
- 配套调整：`bgDeep` / `surfaceSoft` / `greenSoft` 同步去黄；深色模式的土色调换成中性暖黑
- 橄榄绿 `#7D8F52` → `#6B854A`：原来的偏黄，调沉一点与暖白更协调

### 3.7.3

**继续优化丝滑度，去掉设置页版本区域**

- 日程页改用 `LazyVStack`：它原本用普通 `VStack` 把上百条分组一次性全部构建，这是「切到日程页卡一下」的原因
- 缓存页面底色元素：每次新建 JSX 会让 SwiftUI 当成「背景变了」而重绘
- 设置页去掉「版本」行

### 3.7.2

**修复日子页左滑删除闪退**

- 根因：删除绑在左滑的 swipe action 上，而里面又要弹系统确认框 —— 「左滑面板 + 系统弹窗」两个 dismissal 叠在一起就闪退
- 左滑删除改为直接生效（这也是 iOS 原生的做法），确认框只保留在编辑面板
- 去掉 `role="destructive"` 改用 `tint`；关闭 `allowsFullSwipe`

### 3.7.1

**修复删除日子导致闪退**

- 在已呈现的 sheet 上再弹系统确认框会让两个 dismiss 打架
- `saveDays` 这类存储写入从 `setState` 的 updater 里移出（updater 在渲染阶段跑，必须是纯函数）
- `HapticFeedback` 统一包进 `haptic()` 并 try/catch

### 3.7.0

- 优化切页流畅度：回调改 `useCallback`、页面改用 `useMemo`，避免每次切换重建全部页面
