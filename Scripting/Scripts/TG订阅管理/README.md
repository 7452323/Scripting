# TG订阅管理

## 用途
Telegram 频道和订阅数据管理器，获取并缓存受众数据，提供设置页面，并可通过刷新动作静默更新 Widget。

## 首次使用
1. 导入并运行脚本。
2. 在设置页填写 Telegram Bot Token 或项目要求的访问信息。
3. 配置需要统计或展示的频道，手动刷新确认数据。
4. 添加 Widget 后，通过刷新动作更新缓存数据。

## 注意事项
Token 和频道数据属于敏感信息，不要提交到仓库。Bot 必须具备读取目标频道数据所需的权限。
