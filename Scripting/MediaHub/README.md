## 使用
1. 设置 → 选择源类型 → 填协议/主机/端口 → 连接（端口不确定时留 8096 即可，会自动试 443）
2. Plex 先点「Safari 登录 Plex」，再填本地/远程服务器地址连接
3. 首页显示 Emby 的继续观看 / 最近添加 / 电影 / 剧集
