# 115获取Cookie

## 用途
通过 115 二维码登录获取 Cookie，并提供有效性校验、复制、重新获取和清除功能。Cookie 会保存在脚本本地存储中，供需要 115 登录状态的脚本使用。

## 首次使用
1. 导入脚本并运行。
2. 点击二维码登录，用 115 App 扫码并确认授权。
3. 等待脚本完成校验，使用复制按钮取得 Cookie。
4. 重新打开脚本可查看已保存状态，也可以清除后重新登录。

## 注意事项
二维码和登录状态来自 115 官方服务。不要把 Cookie 分享给他人或提交到仓库。
