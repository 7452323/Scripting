# ONE 每日一言

显示 ONE 每日一言内容和配图的主屏幕小组件，支持小、中、大尺寸。

## 首次使用

1. 在 Scripting App 运行“One 每日一言（新）”，确认可加载当天内容。
2. 在主屏幕添加该脚本的小组件，并选择所需尺寸。
3. 在小组件配置中可选择普通、透明或模糊背景模式。

## 数据与刷新
- 小组件缓存有效期为 4 小时；到期后会重新请求内容和背景图。
- 网络暂时不可用时保留最近一次有效内容，避免小组件显示为空。
- 小组件底部的“更新 HH:mm”是最近一次成功拉取时间。
- WidgetKit 会根据系统资源调度刷新，请求时间是最早刷新时间而非严格定时器。

## 注意事项

- 透明、模糊和模拟透明背景模式由系统绘制背景，小组件不会覆盖壁纸。
- 普通模式显示当次获取的每日配图，并根据图像明暗调整文字颜色。
