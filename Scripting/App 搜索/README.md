# App 搜索

## 用途
调用 Apple iTunes Search 与 Lookup API 搜索 App，查看名称、评分、截图、Bundle ID、App ID 等信息，并复制标识或打开商店页面。

## 首次使用
1. 导入后运行脚本。
2. 选择国家或地区，输入 App 名称或关键词。
3. 点选结果查看详细信息。
4. 使用复制按钮复制 Bundle ID、App ID 或其他字段。

## 注意事项
搜索结果受 Apple 地区和接口数据影响；不同地区的应用、价格和可用状态可能不同。
