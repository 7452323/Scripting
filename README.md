# Scripting Script Library

> 个人 Scripting App 脚本库。每个目录都是独立项目；点击脚本名称即可只导入该项目。

[![Scripting](https://img.shields.io/badge/Scripting-iOS%20%7C%20iPadOS-007AFF?logo=apple&logoColor=white)](https://apps.apple.com/app/apple-store/id6479691128)
[![Files](https://img.shields.io/badge/files-166-34C759)](Scripting/Scripts/)

## 使用方式

1. 安装 [Scripting App](https://apps.apple.com/app/apple-store/id6479691128)。
2. 从下表选择一个脚本，点击其名称导入。
3. 回到 Scripting 运行脚本；按脚本需要授予系统权限或填写 Cookie、Token、API Key。

每个链接只对应一个脚本项目。Scripting 不支持一次导入整个 `Scripting/Scripts` 目录；项目中的页面、服务、资源和 Widget 会随该项目一同导入。
