# Scripting Script Library

> 个人 Scripting App 脚本库。每个脚本独立归档，点击脚本名称即可导入到 Scripting。

[![Scripting](https://img.shields.io/badge/Scripting-iOS%20%7C%20iPadOS-007AFF?logo=apple&logoColor=white)](https://apps.apple.com/app/apple-store/id6479691128)
[![Scripts](https://img.shields.io/badge/scripts-166-34C759)](Scripting/Scripts/)

## 使用方式

1. 先安装 [Scripting App](https://apps.apple.com/app/apple-store/id6479691128)。
2. 在下面的脚本清单中找到需要的脚本。
3. 点击脚本名称，直接导入对应脚本。
4. 回到 Scripting 运行脚本；部分脚本需要按说明配置权限或 API。

每个链接只对应一个脚本，不支持把整个目录一次性导入。脚本的组件、页面、服务、存储和资源会随对应项目一起导入。

## 说明

- 点击脚本名称是在 Scripting 中导入该脚本，不是导入整个脚本库。
- 部分脚本需要额外配置 Token、Cookie、API 或系统权限，使用前请查看脚本目录内的说明文件。
- 新增脚本统一放在 `Scripting/Scripts/脚本名称/`，并在本表中添加“脚本名 + 描述 + 单独导入链接”。
