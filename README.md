> 每个链接仅导入一个脚本项目。Scripting 不支持整库导入；项目所需的页面、资源、服务与 Widget 会随对应项目一并导入。

## 开始使用

1. 安装 [Scripting App](https://apps.apple.com/app/apple-store/id6479691128)。
2. 从下方选择需要的项目，点击项目名称打开导入页。
3. 回到 Scripting 运行项目；按需要完成系统权限、Cookie、Token 或 API 配置。

| 项目规模 | 导入方式 | 维护方式 |
| :--- | :--- | :--- |
| 32 个独立项目 | 单项目导入 | 项目内 README 与版本日志 |

## 使用说明

- 涉及第三方服务、账户、受限内容或下载能力的项目，请先确认自身权限与服务条款。
- 部分项目需要额外配置 Cookie、Token、API Key 或系统权限，具体以项目内 README 为准。
- 新项目应放入 `Scripting/项目名称/`，并在本页添加准确的单项目导入链接与功能说明。
