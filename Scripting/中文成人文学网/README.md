# 中文成人文学网

## 用途
通过内置 WebView 浏览短篇分类和长篇章节，处理 Cloudflare 页面，选择内容下载并导出 TXT，也可以合并导出整本小说。

## 首次使用
1. 导入并运行脚本。
2. 在 WebView 中打开站点并等待页面加载。
3. 浏览分类或章节，按需选择单章或整本导出。
4. 在系统文件或分享面板中保存 TXT。

## 注意事项
站点可能出现验证、访问限制或页面结构变化。请仅下载和保存你有权使用的内容，并遵守站点规则。
