# 磁力资源预览

磁力、ED2K 与下载链接的资源信息预览工具。通过 whatslink.info 查询资源名称、文件大小、文件数量、类型与可用截图，并支持收藏和预览图保存。

## 首次使用

1. 在 Scripting App 运行“磁力资源预览”。
2. 粘贴磁力链接、ED2K 链接或 HTTP(S) 下载链接。
3. 点击查询，查看资源名称、体积、文件数量、类型和截图。
4. 可将结果加入收藏，或复制原始链接、保存预览截图。

## 支持内容

- `magnet:?` 磁力链接。
- `ed2k://` 链接。
- HTTP 或 HTTPS 下载链接。
- 番号搜索：使用内置 WebView 查询 MissAV 与 JavDB 的公开页面结果。

## 数据与存储

- 资源元数据查询使用 `https://whatslink.info/api/v1/link`。
- 收藏项目保存于脚本私有 Storage，包括链接、名称、体积、文件数量、类型、封面和收藏时间。
- 保存截图会请求相册权限；首次使用该功能时按系统提示授权。
- 番号搜索受目标站点可用性、网络状态和 Cloudflare 验证影响。

## 注意事项

- 本项目仅用于预览资源元数据及管理用户有权访问的链接。
- 请确认下载、保存和访问内容符合适用法律、版权要求和服务条款。
- 第三方接口可能更改、限流或暂时不可用；此类情况会显示查询错误，不会影响已保存收藏。
