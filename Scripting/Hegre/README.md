# Hegre

## 用途
抓取 Hegre 影片资料，结合文件名中的日期整理标题、演员和元数据，并生成适用于 Kodi/Jellyfin 的 `.nfo` 文件。

## 首次使用
1. 导入并运行脚本。
2. 选择包含符合日期格式文件名的影片文件或目录。
3. 等待脚本抓取公开页面信息并整理元数据。
4. 检查生成结果后，将 `.nfo` 与影片放在对应目录。

## 注意事项
页面通常不提供可靠发布日期，日期主要来自文件名。请确认你有权保存和整理相关内容，并留意网站可访问性。
