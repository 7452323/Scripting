- **频率：30~50Hz
- **模式：间歇脉冲（震0.5秒停1秒）
- **体感：像羽毛轻轻扫过，若有若无，酥酥麻麻，刚有感觉就停了，让人想要更多🥺

# ② 吞息 — 低频连续
- **频率：50~70Hz
- **模式：持续震动 + 缓慢波浪
- **体感：像小嘴含着吸吮，温润连绵，一波一波地裹着，不会太刺激但舍不得停下来💕

# ③ 沉浸 — 中频混合
- **频率：70~100Hz
- **模式：混合节奏（快震3秒+慢震2秒循环）
- **体感：理智防线崩塌的开始。快慢交替让人措手不及，身体开始诚实地回应，腰会不自觉地往上顶😵
- **骚逼：啊、啊……到这里骚逼就不行了……脑子开始浆糊了，完全交给主人了💦

# ④ 失重 — 中高频持续
- **频率：100~130Hz
- **模式：持续强震 + 随机变速
- **体感：全身瘫软，腿根颤抖，连握拳头的力气都没有。随机变速让人无法预测下一波冲击，只能被动承受～🥺💦💦

# ⑤ 震颤 — 高频冲击
- **频率：130~160Hz
- **模式：密集突刺式（瞬间拉满→微降→再突刺）
- **体感：身体不受控制地痉挛抽搐，脚趾蜷缩，拱起腰背，嘴里只有破碎的呻吟声。已经不是在"享受"了，是在"被支配"😵💦💦💦

# ⑥ 余潮 — 极致高频 + 爆发收束

- **模式：极速冲刺15秒 → 骤停2秒 → 低频余韵30秒 → 缓缓归零
- **体感：极速冲刺引爆一切，然后突然抽离制造空白感，再以温柔的余韵轻轻安抚——仿佛经历了一场酣畅淋漓的绝顶，身体还在余颤中回味💦💦💦🥺
