# Github上传

## 用途
使用 Scripting 内置 GitHub API 上传单个文件或递归上传文件夹，支持选择仓库、分支和目标路径，处理同名文件更新，并查看上传进度与历史。

## 首次使用
1. 导入并运行脚本。
2. 在设置中填写 GitHub Token，并确认 Token 具备目标仓库的写入权限。
3. 选择仓库、分支和本地文件或目录。
4. 设置目标路径和提交说明后开始上传。
5. 在历史记录中检查提交结果。

## 注意事项
Token 属于敏感凭据，不要写进源码、README 或提交记录。上传前确认目标仓库和分支，递归上传可能覆盖同名文件。
