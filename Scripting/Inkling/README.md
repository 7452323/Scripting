# Inkling · 微信读书划线回顾

把散落在微信读书里的划线、想法和阅读数据接回本地，变成可以反复翻到的卡片。

- 数据源：微信读书官方 Agent API（`wrk-` API Key）
- 存储：笔记缓存在本机 Storage，API Key 存在本机 Keychain
- 入口：`index.tsx`（`Navigation.present` 呈现，`Script.exit()` 退出）

## 获取 API Key

1. 打开 https://weread.qq.com/r/weread-skills
2. 用要连接的微信读书账号扫码登录
3. 复制页面上 `wrk-` 开头的 Key，粘进 Inkling 首页

## 界面结构

| 页面 | 内容 |
| --- | --- |
| 重温 | 计数与「全部 / 划线 / 想法」筛选；卡片式正文，底部书籍缩略图 + 书名作者（可点进详情）；上一条 / 下一条 + 复制；右上角重洗牌堆；未缓存的笔记可手动继续加载 |
| 书架 | 真实封面墙（LazyVGrid 自适应列）；本地搜索书名作者，搜不到时可一键跳书城搜索；顶部显示书目 / 笔记条数 / 上次同步时间；右上角同步并后台预下载笔记 |
| 我的 | 本周/本月/今年/全部切换；书目 / 笔记 / 时长三宫格，下方一行展示读过 / 读完 / 阅读天数与偏好；更换 Key、获取 Key；为你推荐、接口诊断；清缓存、退出登录 |
| 书详情 | 封面 + 书名作者 + 划线想法计数 + 跳回微信读书；信息卡（推荐值 / 篇幅 / 点评数 / 简介展开 / 读者点评入口 / 阅读进度与目录）；「大家都在划」热门划线；笔记卡片流；相似书横滑 |
| 二级页 | 读者点评（星级筛选 + 分页）、目录（章节热门划线热度 + 去原文）、划线下的想法（单条详情）、为你推荐、书城搜索、接口诊断 |

界面参考对象：Booko（封面墙 + 卡片回顾）、随手摘 QuoteKeep（重温卡片 + 上下翻页 + chip 筛选）、书影（卡片底部书籍归属行 + 章节标签）。

## 用到的接口

统一网关 `POST https://i.weread.qq.com/api/agent/gateway`，`Authorization: Bearer <wrk-key>`，
业务参数与 `api_name`、`skill_version` 平铺在 body 顶层。

| api_name | 用途 | 本脚本 |
| --- | --- | --- |
| `/_list` | 列出网关所有可用接口与参数定义 | ✅ 接口诊断页 |
| `/shelf/sync` | 完整书架（校验 Key；失败会中止同步，不覆盖缓存） | ✅ |
| `/user/notebooks` | 有笔记的书（`lastSort` 游标 + 多重兜底） | ✅ |
| `/book/bookmarklist` | 单本书划线 + 章节表 | ✅ |
| `/review/list/mine` | 单本书我的想法/点评（`bookid` 小写，`synckey` 游标） | ✅ |
| `/readdata/detail` | 阅读统计（周/月/年/全部；读过、读完、天数、偏好词） | ✅ |
| `/book/bestbookmarks` | 全书热门划线（前 20 条，含划线人数） | ✅ 大家都在划 |
| `/book/info` | 书籍详情（评分 / 简介 / 点评数） | ✅ 信息卡 |
| `/book/chapterinfo` | 完整目录（chapterUid ↔ 标题） | ✅ 目录面板 |
| `/book/getprogress` | 单书阅读进度与累计时长 | ✅ 信息卡 |
| `/book/underlines` | 章节划线热度（不含原文） | ✅ 目录展开 |
| `/book/readreviews` | 某条热门划线下的想法 | ✅ 划线想法面板 |
| `/review/single` | 单条想法详情 | ✅ 想法详情 |
| `/review/list` | 公开书评（星级筛选 + 分页） | ✅ 读者点评 |
| `/store/search` | 书城搜索（书名 / 全文） | ✅ 搜索页 |
| `/book/recommend` | 个性化推荐 | ✅ 为你推荐 |
| `/book/similar` | 相似书推荐 | ✅ 详情页底 |

**接口能力边界**：`/book/underlines` 只给字符偏移 `range` 与人数、**不返回原文**（所以目录里只展示热度，原文要点「去原文」跳 App）；`/user/notebooks` 的 `bookmarkCount` 是页码书签，拉不到内容，界面统计只算 `noteCount + reviewCount`。

## 深链（跳回微信读书 App）

```text
书籍：  weread://reading?bId={bookId}
章节：  weread://reading?bId={bookId}&chapterUid={chapterUid}
划线：  weread://bestbookmark?bookId={bookId}&chapterUid={chapterUid}&rangeStart={start}&rangeEnd={end}
```

`range` 形如 `900-2004`，前后两段分别填 `rangeStart` / `rangeEnd`。

## Key 的能力边界

- ✅ 只读：书架、书籍信息、目录、阅读进度、统计、划线、想法、热门划线、公开书评、推荐
- ❌ 不能写：新增/修改/删除划线、导入书籍、公众号、AI 问答 —— 这些需墨水屏客户端的另一套扫码鉴权，不在 `wrk-` Key 的权限内

## 注意

- 划线接口只返回划线，书签仅有数量统计，拿不到书签内容
- 封面优先用接口返回的 `cover`，缺失时按 bookId 拼 CDN 地址
- 微信读书接口可能随时调整；`upgrade_info` 出现时脚本会提示需要升级
