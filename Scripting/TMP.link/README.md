# TMP.link

## 用途
TMP.link 文件分享客户端，使用 Token 管理远程文件，支持从相册或文件选择器上传、分片上传、设置有效期、删除文件和复制分享链接。

## 首次使用
1. 导入并运行脚本。
2. 在设置中填写 TMP.link Token。
3. 从文件或相册选择要上传的内容，设置有效期后开始上传。
4. 上传完成后复制分享链接；可在文件列表中删除远程文件。

## 注意事项
Token 仅保存在本机。上传和分享前确认文件内容、有效期及服务条款，分片上传大文件时请保持网络稳定。
