# MediaHub

## 用途
全能媒体播放器基础框架（第一阶段）。提供原生 AVPlayer 播放、媒体库管理、播放历史，并预留 Emby / Plex / 115 网盘 / 自定义脚本源扩展接口。

## 当前功能（v0.1.0）
- 原生视频播放（AVPlayer + AVPlayerView）
- 支持远程直链、HLS、本地文件
- 画中画（PiP）与 Now Playing 支持
- 媒体库：添加 URL / 本地文件、删除、收藏
- 播放历史记录
- 现代化标签页 UI（媒体库 / 正在播放 / 设置）

## 规划中
- Emby / Plex 客户端
- 115 网盘浏览与播放
- 自定义 JS / Python 脚本源（类似 REX）
- 元数据刮削（参考 SenPlayer）
- 字幕 / 音轨高级管理

## 首次使用
1. 导入并运行脚本。
2. 在「媒体库」中添加远程视频 URL 或选择本地文件。
3. 点击条目即可进入原生播放器。
4. 后续版本将逐步加入服务器与脚本源支持。

## 注意事项
请仅播放你有权访问的内容。涉及第三方服务时，请遵守对应服务条款。
